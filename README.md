## 🚀 Featured Projects

### 💊 Faraz Pharmacy POS — Offline Desktop POS
> Electron.js · Node.js · Express · Prisma · PostgreSQL · ESC/POS · ZPL · LAN

A robust offline-first desktop POS system built for pharmacies. Manages inventory, sales, billing, and reporting without internet dependency. Features thermal receipt printing (Sewoo ESC/POS via USB), label printing (Zebra ZPL via CUPS), and USB barcode scanner integration. Runs seamlessly across multiple machines on a local network.

---

### 🏥 PMS Cloud — Multi-Tenant Pharmacy SaaS *(in progress)*
> Next.js · FastAPI · PostgreSQL · SQLModel · Multi-Tenancy · Docker

A cloud-based multi-tenant pharmacy management system with per-tenant data isolation, role-based access control, medicine inventory management, and sales tracking. Built as a scalable SaaS platform with a modern Next.js frontend and FastAPI backend.

---

### 🏫 Maktab One — School Management SaaS
> Next.js · Node.js/Express · Prisma · PostgreSQL · JWT · Docker · TypeScript

A production-grade multi-tenant school management system with full auth (JWT access/refresh tokens, OTP device verification, Remember Me), dynamic RBAC, student enrollment, guardian automation, bulk CSV import, and fee tracking. Deployed with Docker + NGINX.

🔗 [Live: schoola.maktabone.org](https://schoola.maktabone.org/)

---

> Docker · NGINX · Linux · SSH · GitHub Actions · Kubernetes · CI/CD

A structured, hands-on DevOps learning repo with detailed notes, real configs, and ready-to-use CI/CD pipeline templates for 5 stacks (Next.js, Node.js, FastAPI, Laravel, monorepos). Documents everything from Docker fundamentals to Kubernetes and cloud deployment.

### 🏢 TaskFlow — Multi-Tenant Task Manager
> Next.js · Node.js · Express · PostgreSQL · Docker · TypeScript

A multi-tenant task management system with per-tenant data isolation, RBAC (Admin, Team Members), full task and member CRUD, containerized with Docker Compose + NGINX reverse proxy.
